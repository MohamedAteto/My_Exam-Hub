### Exams Hub
- Definition：The name of this monorepo project — a web application for managing academic examinations, serving administrators, teachers, and students.
- Aliases：Exam-Hub、Exams_Hub

### ElsewedySchoolSysDB_DEV
- Definition：The development SQL Server database name used by the backend's EF Core context; the production database name is not specified in the repo.

### CAS.Api
- Definition：The JWT `Issuer` claim value configured in the backend; tokens issued by this service are validated against it on the client side.

### CAS.Clients
- Definition：The JWT `Audience` claim value configured in the backend; tokens must be intended for this audience.
