The repository is split into two sibling projects — `client/` (React + Vite SPA) and `server/api/` (.NET 9 REST API backed by Entity Framework over SQL Server). The client authenticates users via CAS SSO and calls the server's REST endpoints from the browser; the server exposes exam, question-bank, dashboard, and auth APIs consumed by role-gated UI routes. There is no shared code or build pipeline between the two sides — each project is developed, built, and run independently as described in README.md.
