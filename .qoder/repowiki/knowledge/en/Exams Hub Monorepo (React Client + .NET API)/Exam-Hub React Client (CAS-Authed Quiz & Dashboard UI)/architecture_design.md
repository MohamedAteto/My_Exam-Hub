- Entry point `src/main.jsx` bootstraps a `react-router-dom` v7 `createBrowserRouter`, mounting public routes (`/`, `/sso-callback`, `/signed-out`, `/greeting`) and role-protected routes (`/student`, `/teacher`, `/superadmin`, `/student-details`) wrapped in `<ProtectedRoute allowedRoles={...}>`.
- Authentication is handled by redirecting unauthenticated users to the CAS server (`VITE_CAS_URL`) and processing the callback in `SsoCallbackPage`; tokens are stored via `src/utils/storage.js` which transparently switches between `localStorage` and `sessionStorage` based on a persist flag and exposes `logoutFromCas` for server-side logout.
- API access is centralized in `src/api/axios.js`: an Axios instance adds a `Bearer` token from storage on every request and globally intercepts 401 responses by clearing storage and re-directing to CAS login; base URL comes from `VITE_API_BASE_URL` (defaults to production endpoint).
- Role-based rendering uses `src/utils/token.js` (`parseToken`, `getUserIdFromToken`) to decode JWT payloads and `src/utils/roleUtils.js` (`isStudent`, `isTeacher`, `isSuperAdmin`) for UI-level guards; `ProtectedRoute` falls back to a stored `userRole` when token parsing fails.
- Feature pages live under `src/pages/` (Student, Teacher, SuperAdmin, StudentDetails, Greeting, Login, SsoCallback, ExamSignedOut) and compose reusable presentational components under `src/components/` (DashboardView, UnifiedDashboard, Sidebar, ProtectedRoute, QuizInterface, QuizModal, FileUpload, RichTextEditor, ModernDatePickers, MultiSelectDropdown, ErrorBoundary, LoadingSpinner, Profile/UserProfile, charts via Recharts).
- Build/dev tooling: Vite config pins port 5177 with strict mode; a separate Express proxy (`setupproxy.js`) forwards `/api` to `http://127.0.0.1:5077` during development; environment-specific configs in `.env.development` / `.env.production` drive API/CAS endpoints.
