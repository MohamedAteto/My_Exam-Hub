Startup seeds the database via `Models.ElsewedySchoolContextSeed.SeedAsync` inside `Program.Main`; migrations live under `Api/Migrations/`. A PowerShell helper `check_db.ps1` and several `.sql` scripts (`migrate_data.sql`, `cleanup_users.sql`) are provided for manual DB maintenance. Appsettings split into `appsettings.json`, `appsettings.Development.json`, `appsettings.Production.json`.
